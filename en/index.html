Pixline privacy policy

Version of 10 November 2026

Pixline is a puzzle game for Android. This policy describes what data the game processes. In short: the game does not collect, send or share any data, and the controller has no access to it.

Controller

Maciej Libucha, an individual, not acting as a business.
Contact: maciejlibucha01@gmail.com

What data is stored in the game

The game stores only the data it needs to play, on the device:

  • campaign progress (completed levels, current level, whether the tutorial is done, number of hints),
  • settings (vibration, animations).

This data stays in the app's storage on the device. It is not sent to the controller or to any other company. It can be deleted by resetting progress in the game settings or by uninstalling the game.

Google backup

The game lets Android include its saved data (progress and settings) in the Google account backup and in transfers to a new phone. Android does this according to the device's backup settings, and the data is stored by Google. This can be turned off in system settings (Google, Backup). The controller has no access to these backups.

What the game does not do

  • It does not show ads.
  • It has no internet access and sends no data off the device.
  • It needs no account or registration.
  • It contains no analytics, crash reporting or third-party trackers.
  • It does not ask for location, contacts, camera, microphone or photos. It only uses vibration, unless this is turned off in the game settings.

Children

The game is not directed at children. It does not collect any data, including from children.

Rights of data subjects

Because users' personal data is not processed, there is no data to be made available, corrected or deleted. Questions can be sent to the address above. There is also a right to lodge a complaint with a supervisory authority; in Poland this is the President of the Personal Data Protection Office (uodo.gov.pl).

Changes to this policy

If a future version of the game changes how data is processed, for example by adding ads, this policy will be updated before that version is released. The current version date is at the top of the page.
